# Change Log

All notable changes to the "DotEnv Manager" extension will be documented in this file.

## [4.2.0]

- **New**: Custom editor view — open any .env file in a rich management UI
- **New**: Visual table with grouping by prefix, search/filter, inline editing
- **New**: Secret masking with click-to-reveal in the manager view
- **New**: Add, edit, and delete variables directly from the UI
- **New**: Generate .env.example from the manager toolbar
- **New**: Copy variable values to clipboard
- **New**: "Open with DotEnv Manager" command and context menu entry
- **New**: Auto-completion for common environment variable names
- **New**: Real-time diagnostics for duplicate keys and malformed lines
- **Removed**: Sidebar tree view and webview panel (replaced by custom editor)
- **Changed**: Streamlined command set focused on the custom editor workflow

## [4.1.0]

- Initial release
